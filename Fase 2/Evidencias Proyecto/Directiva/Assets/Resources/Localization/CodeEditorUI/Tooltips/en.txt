[new_script]: Create script
[new_folder]: Create folder
[save]: Save changes
[revert]: Revert changes
[stop]: Stop execution
[pause]: Pause execution
[continue]: Continue execution
[step]: Execute next instruction
[step_in]: Step into current call
[step_out]: Step out of current call
[back]: Back
[options]: Options
[expand_folder]: Expand folder
[collapse_folder]: Collapse folder
[collapse_output]: Collapse Output
[expand_output]: Expand Output
[clear_output]: Clear Output
[entry_function]: Name of a parameterless DScript function to run. Leave blank to run the first function in the selected file.
[debug_source]: Highlights the DScript line currently executed by the VM. DEBUG_* metadata is always generated.
[execution_metrics]: Executed Advances and elapsed real time, including pauses. DEBUG_* counts as Advances.
