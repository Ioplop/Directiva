# Directiva Code UI v1.12

Output alignment and symbolic file controls.

Changes:

- Output header now grows with `Output Font Size` instead of remaining fixed at 32 px.
- Output title and filter labels receive explicit vertically centered control heights.
- Collapsed Output height now follows the zoomed header height, avoiding clipping at large zoom levels.
- New Script is now represented by `＋≡`.
- New Folder is now represented by `＋▰`.
- Save is now represented by `✓`.
- Revert is now represented by `↶`.
- All symbol-only controls retain localized tooltips.
- Explorer creation symbols scale with Explorer zoom.

No storage, language, execution, refactoring or editor-metric behavior changed.
