# Directiva Code UI v1.2

Visual/readability and Output behavior patch based on the first runtime test.

Changes:

- Increased contrast across labels, buttons, disabled buttons, explorer rows, Output and dialogs.
- Explicitly sets the code editor caret to white and selection to a visible blue tint.
- Applies the same caret/selection treatment to modal text fields.
- Fixed Output collapse so the whole panel actually shrinks to its header height.
- Remembers the previous expanded Output height and restores it when reopening.
- Added distinct folder and script symbols in the explorer.
- Added localized tooltips for folder/script symbols.
- No language/analysis/refactoring behavior changes.
