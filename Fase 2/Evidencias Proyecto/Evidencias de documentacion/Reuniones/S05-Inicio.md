## Qué debe cubrir el plan de pruebas del lenguaje

Probar al menos las funcionalidades acordadas:

- Definición y uso de **variables**.
  - entero
  - decimal
  - booleano
  - texto
  - lista
  - diccionario
  - set
- Definición y uso de **funciones**.
- **Estructuras de control**.
- **Importación** de scripts/módulos.
- Verificar tanto que las operaciones se puedan realizar como que **produzcan el resultado correcto**.

Idealmente usar una planilla tipo casos de prueba con campos como:

`Caso / acción → resultado esperado → resultado obtenido → estado`
