
**Este directorio contiene una serie de resumenes de todas las reuniones realizadas, siguiendo los siguientes códigos:**

S[semana]-[Inicio/Retrospectiva/D[número]]

### Ejemplo

S07-Inicio  -> Reunión inicio sprint semana 7

S05-Retrospectiva -> Reunión de retrospectiva o fin de sprint, semana 5

S12-D2 -> Daily número dos de semana 12

**Los archivos pueden ser .md, .pdf o .txt. Contienen resúmenes de lo conversado en las reuniones y se preservan aquí como evidencia de que las reuniones fueron realizadas.**
